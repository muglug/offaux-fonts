OFFAUX FONTS

A collection of OFL-licensed fonts modified to be metric-compatible with ones common in Microsoft Word documents. The typefaces below are useful in situations where the equivalent fonts cannot be used for licensing reasons, e.g. when generating PDFs server-side.

These stand-ins are not perfect — in some cases the fonts don't cover the full character set of the ones they aim to replace, and a few of the characters look a little wonky, but they're good enough for most Latin text.
